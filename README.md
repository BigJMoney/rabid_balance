# rabid_balance
Files for a Minecraft Modpack I'm working on; currently organized in more of a project/workshop structure, and not at all in an actual modpack structure, yet.

/configs/: Mod config files and a few config files for my own external scripts used for balancing and making the pack
/docs/: Data docs used to support making the pack
/scripts/: Both my own scripts used to make and balance the modpack, as well is game scripts (e.g. KubeJS)
/sourcelibs/: My own datapack(s) that will be used in the final modpack
